# OCRScan

เว็บแอปอ่านข้อความจากรูปภาพและ PDF ภาษาไทย/อังกฤษ

## เปิดแอปแบบง่าย

ดับเบิลคลิก `เปิด-OCRScan.bat` แอปจะเปิดหน้าเว็บให้โดยอัตโนมัติ ต้องติดตั้ง Node.js ไว้ในเครื่อง

หรือเปิด Terminal ในโฟลเดอร์นี้แล้วรัน `npm start` จากนั้นเปิด <http://127.0.0.1:4173>

## วิธีใช้งาน

1. เลือกรูปภาพหรือ PDF (เลือกหลายไฟล์ได้)
2. เลือกภาษา แล้วกด **อ่านข้อความ**
3. แก้ไขผลลัพธ์ได้ จากนั้นกดคัดลอกหรือดาวน์โหลด `.txt`

รองรับ JPG, PNG, WEBP, BMP, GIF และ PDF หลายหน้า ขนาดไม่เกิน 40 MB ต่อไฟล์

แอปใช้ Tesseract.js และ PDF.js จาก CDN จึงต้องเชื่อมต่ออินเทอร์เน็ตเมื่อเปิดใช้ครั้งแรกหรือดาวน์โหลดข้อมูลภาษา ส่วนเอกสารจะถูกอ่านในเบราว์เซอร์และไม่ถูกอัปโหลดไปยังเซิร์ฟเวอร์ของแอป
