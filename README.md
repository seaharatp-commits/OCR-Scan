# OCRScan

เว็บแอปอ่านข้อความจากรูปภาพและ PDF ภาษาไทย/อังกฤษ โดยใช้ EasyOCR โมเดลสำเร็จรูป

## เปิดแอปแบบง่าย

ติดตั้ง EasyOCR ครั้งแรกโดยดับเบิลคลิก `ติดตั้ง-EasyOCR.bat` (ต้องติดตั้ง Python 3.11 และ Node.js ไว้ก่อน) จากนั้นดับเบิลคลิก `เปิด-OCRScan.bat` แอปจะเปิดหน้าเว็บให้โดยอัตโนมัติ

หรือเปิด Terminal ในโฟลเดอร์นี้แล้วรัน `npm start` จากนั้นเปิด <http://127.0.0.1:4173>

## วิธีใช้งาน

1. เลือกรูปภาพหรือ PDF (เลือกหลายไฟล์ได้)
2. เลือกภาษา แล้วกด **อ่านข้อความ**
3. แก้ไขผลลัพธ์ได้ จากนั้นกดคัดลอกหรือดาวน์โหลด `.txt`

รองรับ JPG, PNG, WEBP, BMP, GIF และ PDF หลายหน้า ขนาดไม่เกิน 40 MB ต่อไฟล์ OCRScan ใช้เฉพาะภาษาไทยและอังกฤษ

EasyOCR จะดาวน์โหลดโมเดลที่ฝึกไว้แล้วในครั้งแรก ไม่ต้องฝึกโมเดลเอง ไฟล์เอกสารถูกส่งไปยังบริการ EasyOCR ในเครื่องเดียวกันเท่านั้น ไม่ได้อัปโหลดออกอินเทอร์เน็ต

หากยังไม่ได้ติดตั้ง Python/EasyOCR แอปจะใช้ Tesseract.js เป็นตัวสำรองในเบราว์เซอร์

หมายเหตุ: EasyOCR รุ่นนี้เน้นข้อความพิมพ์ ลายมืออาจอ่านได้ไม่ครบ ควรตรวจทานผลลัพธ์
